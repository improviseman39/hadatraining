# HOW TO REPORT TO HK

Every time you finish working (before you stop or wait for the user), ALWAYS
end your reply with exactly this block, in plain English, no code words:

WHERE WE ARE: X of Y Phase 1 features done (Z%) - full list: docs/STATUS.md
WHAT I JUST DID: 3-5 short bullet points
WHAT'S NEXT: the next 3 features you will build
WHAT I NEED FROM YOU: numbered steps (where to click, what to paste), or "Nothing - type continue"
HOW TO CONTINUE: the exact thing I should type

This block is required at the end of every reply where work was done this
turn - not just at the end of a whole task. If `docs/STATUS.md` doesn't
exist yet or doesn't list Phase 1 features, say so plainly in the WHERE WE
ARE line instead of guessing at numbers.
